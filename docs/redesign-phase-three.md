# 第三階段：購物與小屋的個性

日期：2026-10-24。開始前工作目錄乾淨，基準為第二階段 commit 9190949。本批不推送、不部署。

## 完成內容

- 購物介紹、試玩、原因問答、加入／修改提示、空狀態、決定視窗及存錢目標改成較短的台灣口語。區分首次空清單、分類無結果與搜尋無結果。
- 購物與家具商店畫面的 G 統一為「金幣」，例如「確認購買 40 金幣並擺放」。金額仍為 NT$，金幣仍是遊戲點數。
- 不買成功改用小兔回應與金幣標籤；以既有小兔 SVG 做一次短跳動與三顆金幣跳出，1.5 秒後結束。實際數量讀取已儲存決定的 rewardCoins，不在動畫中計算、發放或保存金幣。
- 只有原本儲存成功後才建立回饋；儲存失敗不播放，原因仍留在視窗內。決定購買只顯示確認，不顯示不買獎勵。
- 回饋以決定 ID 區分；切換購物頁籤不重新建立回饋，因此不重播。重新載入只讀取歷史紀錄，不自動慶祝。
- 成功後直接帶到回饋區，避免手機跳回頁首而錯過動畫。移除重複的成功播報，裝飾圖層不接收點擊、不加入螢幕閱讀器訊息。
- prefers-reduced-motion 下隱藏跳出的金幣並停用回饋動畫，文字結果與實際金幣標籤繼續顯示。
- 空清單不放三張零值成果卡；有成果後用較輕的文字列整理。避免支出與自行存下仍分開，明確說明避免支出不是銀行存款。
- 「即將推出」的畫面入口改顯示為「房間風格」，保留三間房的免費試住、主題介紹和六件付費物品試擺；仍不開放真實付款。
- 小屋只在展示列顯示一次房名，取消遮住房間的重複標籤。主題介紹改寫具體場景，不再堆疊抽象的「努力、慢慢、日常」句型。
- 成長裝飾說清楚是達到累積不買獎勵後可用，不會扣金幣；既有解鎖門檻、收藏及收起操作不變。
- 共用的購物空狀態與小兔成功回應放在 src/ui/shopping-copy.ts，均有實際使用，方便之後修改。

## 本機預覽

1. 開啟 http://127.0.0.1:5182/#/shopping 。展開「新手試玩與使用說明」，按「開始獨立試玩」。
2. 輸入「衣服」、1500 元、7 天冷靜期，加入清單。
3. 按「試玩快轉 7 天」，回顧並寫一句原因，再按「決定不買，留下這筆錢」。應看到小兔、+50 金幣與不代表銀行存款的說明。
4. 切到小屋再回清單，動畫不應重播。按「房間風格」可試住、試擺；付費物品仍不能買。
5. 按「結束試玩」回到自己的紀錄。試玩不會寫入正式清單。
6. 在系統開啟減少動態效果後，可確認文字結果保留、跳動與飛出金幣停止。
7. 若伺服器未啟動，執行 npm.cmd run dev -- --host 127.0.0.1 --port 5182 --strictPort。完整驗證為 npm.cmd run build:verified。
