# 記帳流程收尾

基準 53ecf7d；修改前 Git 工作目錄乾淨。這次補齊既有記帳流程，不新增依賴、API、儲存格式或分類值。

## 變更

- 快速記帳與記帳頁都顯示實際記帳日期，可展開「改日期」補記。修正手動清空日期後無法重新輸入的問題；未填有效日期不能送出。
- 快速記帳送出後，可「撤回剛剛這筆」。只撤回目前面板最後一次成功新增的支出；失敗時不顯示已撤回。下一筆正在輸入的金額與備註會保留，先前成功提示會清掉。
- 新增與修改使用同一組金額、分類標籤、選填備註、日期表單。修改保留原紀錄 ID、購物來源等既有欄位，未填備註時沿用分類名稱。
- 共用底部面板的開啟、Escape、關閉及焦點返回行為，減少重複維護。
- 明細依日期由新到舊顯示，排序不改動儲存陣列。原本編輯、刪除復原、預算統計與跨分頁衝突保護保留。

## 驗證

npm run build:verified 通過：64 項單元／流程測試、48 項介面測試，共 112 項；正式建置及離線資源檢查通過。

新增整合測試涵蓋：補記舊日期、撤回保留下一筆草稿、重新送出只存一筆、修改與刪除復原保留購物來源，以及跨分頁更新時不覆寫新資料。既有首頁預算同步、連續記帳及失敗保留草稿測試維持通過。

隔離本機驗收站確認新增 120 元後餘額 380 元，修改成 95 元後餘額 405 元。測試資料與平常的 5182 來源不同，沒有寫入使用者原有記帳資料。瀏覽器驗證的是桌面畫面；這次的手機尺寸設定未生效，因此不當作實機手機／軟鍵盤驗收。

## 本機驗收

http://127.0.0.1:5182/#/ ：點「記一筆」，展開「改日期」，可先選日期後取消，不會新增紀錄。

http://127.0.0.1:5182/#/budget ：新增後修改同一筆支出，確認金額、分類、日期及預算同步；刪除後用「復原上一筆」找回。正式紀錄操作前可先到「更多」匯出備份。

要測試撤回：使用測試資料記一筆，再開始輸入下一筆；按「撤回剛剛這筆」時，應只撤回前一筆、保留手上的草稿。關閉面板後，不保留這個臨時撤回入口；既有紀錄仍可在記帳頁刪除並復原。

如預覽尚未啟動：npm run dev -- --host 127.0.0.1 --port 5182 --strictPort。
