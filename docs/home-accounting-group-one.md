# 第一組：首頁重心、底部分頁與快速記帳

2026 年 10 月 24 日。開始前工作目錄乾淨，基準 abd27d3。本次依新清單完成兩份清單的第一組，第二、三組尚未進行。本機提交，不推送或部署。

## 完成內容

- 主導覽統一為底部四個分頁：首頁、記帳、想買、更多。移除上方七個連結；既有工具、週回顧、首頁工具設定、成長、簽到、備份與安裝說明集中至「更多」。原有工具網址仍可直接開啟。
- 首頁內容依序為今日預算、明顯的「記一筆」、今日花費明細、小屋、想買入口。「新增想買物品」使用次要按鈕。今日明細先列五筆，更多時可查看全部。
- 小屋與商店改為獨立的 #/house，首頁「佈置小屋」及更多頁均可進入。冷靜清單只保留「清單／省錢回顧」兩個分頁；決定不買後仍可前往小屋。獨立試玩仍與正式紀錄分離。
- 首頁「記一筆」開啟原生 dialog 底部面板；日常預算頁最上方也使用同一份記帳表單。順序是金額、分類標籤、選填備註。
- 金額使用數字輸入與 decimal 鍵盤提示，自動對焦，淺灰 placeholder「輸入金額」。送出成功後清空金額／備註、保留分類、重新對焦，可連續輸入；不彈出確認視窗。
- 最近一次支出的分類會作為下次預設。備註未填時，既有明細的 text 使用分類名稱；沿用原有 Entry 欄位、儲存鍵與儲存格式，不另存分類偏好。
- 成功時金額短暫向上移動、首頁預算卡輕微回饋，小兔隨機說一句話；同一面板內避免連續相同話語。動畫尊重 prefers-reduced-motion。小兔句子集中於 src/ui/expense-copy.ts。
- 儲存失敗保留輸入、不發成功提示；沿用原有分頁衝突檢查，避免覆寫其他頁面剛更新的資料。取消／Escape 關閉後回到原按鈕。

## 本機預覽與驗收

開啟 http://127.0.0.1:5182/#/ 。若服務未啟動：npm run dev -- --host 127.0.0.1 --port 5182 --strictPort。

1. 確認首頁順序及底部四分頁；「想買」頁沒有小屋商店分頁，「更多」仍找得到其他工具及備份。
2. 點「記一筆」，確認金額立即對焦、分類可點、備註可留白。可先只開啟後取消，這不會新增任何支出。
3. 要測試送出時，建議使用獨立瀏覽器或測試資料。連記兩筆，確認金額／備註清空、分類保留、金額重新對焦、預算與今日明細更新。重新開啟記帳面板，確認分類沿用最近一筆。
4. 點底部「記帳」，確認同一表單在頁面最上方，原本編輯／刪除／復原及 CSV 仍可使用。
5. 首頁「佈置小屋」進入獨立小屋頁，重新整理仍能開啟，已購家具與擺放不變。
