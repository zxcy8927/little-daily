# 手機尺寸模擬驗收報告

版本：1.4.0。驗收日期：2026-10-19。

## 結論

本輪手機尺寸瀏覽器模擬驗收通過，並修正一項 320px 螢幕橫向溢出問題。這是 Chromium 瀏覽器視窗模擬，不是 Android Emulator、iOS Simulator 或實體手機驗收，不能取代原生通知、安裝、系統分享與背景行為的測試。

使用獨立的 `localhost:4175` 正式建置版，與原有 `localhost:5173` 資料分開。所有新增資料均為命名清楚的測試紀錄；沒有修改原有使用者紀錄。驗證離線時已停止此獨立測試伺服器。

## 發現及修正

`src/index.css` 原本將 body 最小寬度設為 320px；320px 視窗扣掉捲軸後實際可用 305px，造成約 15px 橫向溢出。已改為 `min-width: 0`，重新建置並同步 Android／iOS 資源，再完成兩輪尺寸複查。

正式離線資源檢查與手機專案資源一致性檢查皆通過。沒有因這次瀏覽器模擬而將 `androidDeviceTested`／`iosDeviceTested` 改為 true。

## 仍未驗收

- Android／iOS 原生安裝包建置、簽章、安裝與升級。
- Android System WebView 與 iPhone Safari／WKWebView 的實際差異。
- 真實觸控、輸入法鍵盤、自動填入、相機安全區域與硬體返回鍵。
- 系統通知權限、真實送達、點擊及背景／重開機後行為。
- 原生檔案副本的真實裝置復原，以及 Files／分享選單匯出與匯入。
- 系統低空間、程序被強制關閉、系統字體放大與系統無障礙服務。

這些項目仍需有手機或完整原生模擬器與相應建置環境後測試。本輪不把「縮放視窗」視為模擬了作業系統、輸入法或系統權限。
