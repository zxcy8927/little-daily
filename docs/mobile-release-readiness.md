# 手機測試與上架準備狀態（1.4）

更新：2026-10-19。已建立 Android 與 iOS 原始專案，尚未編譯出 APK／AAB／IPA，也未送商店審核。

## 這一版已完成

- 六個日常工具、首頁摘要、每週回顧、首次導覽、自訂首頁及離線網頁版。
- 購物冷靜期 1／3／7 天；修改考慮中物品保留原到期時間；撤回可復原。
- 不買決定、避免支出、手動確認已存金額、單筆一次金幣獎勵、三種可收起／擺放的裝飾。
- 存錢目標、每月回顧及 CSV 匯出；避免支出與銀行存款分開。
- 獨立試玩與快轉，不寫入正式工具紀錄、不排通知。
- JSON 備份／合併匯入、同瀏覽器五份自動復原點、資料驗證與衝突保護。
- Capacitor Android／iOS 專案與原生插件整合。Android 的返回鍵處理、通知小圖示、App 圖示及啟動畫面已準備；iOS 已加入檔案 API 隱私資源。
- 原生副本：私有資料目錄交替兩份，帶版本序號及資料驗證；網站儲存完全空白才嘗試復原。現有紀錄優先，不以舊副本自動覆寫；兩份皆無法驗證時停止寫入並顯示訊息。
- 原生 JSON／CSV 匯出使用系統分享選單，由使用者選儲存位置；網頁使用下載。
- 原生到期提醒的權限請求、關閉、排程及點擊返回購物工具已接好。預設關閉，只排最近 32 筆未到期／未決定物品，不含名稱、金額；未加入精準鬧鐘權限，送達時間受系統管理。
- 原生版不註冊網頁 Service Worker，資源隨安裝包提供；網頁仍保有離線更新流程。

## 驗證證據與界線

- 網頁正式建置、程式測試、離線資源檢查及 Android／iOS 資源同步檢查。
- 裝置副本測試使用模擬檔案介面，涵蓋單槽毀損復原、雙槽毀損保留原檔、現有資料優先及交替寫入。
- 通知測試驗證選擇、排序、數量上限與排除敏感內容；不是通知實際送達驗證。
- 瀏覽器已實測衣服 NT$1,500 的試玩、不買、金幣及裝飾解鎖；也驗證修改、撤回與復原、存錢目標。
- 沒有宣稱 Android／iPhone 實機、系統分享、背景通知或原生副本已通過實機驗收。
- 主要操作資料仍使用網站儲存，原生檔案為另外副本，尚非完整原生資料庫；非同步寫入中若強制終止仍可能失去最近修改。卸載 App 或裝置損壞不受副本保障。

## 本機建置

1. `npm install`、`npm test`。
2. `npm run mobile:sync`：正式建置並同步兩個平台。
3. `npm run check:release` 及 `npm run mobile:check`：檢查離線檔案與兩平台拷貝是否一致。
4. Android：安裝官方 Android Studio／SDK，確認 Java，執行 `npm run mobile:android`，用實機或模擬器建置。這台機器尚未找到 Java／SDK。
5. iOS：將完整專案放在具 Xcode 的 Mac，安裝依賴後再次執行同步，以 `npm run mobile:ios` 開啟。Swift Package 依賴需首次連線解析。
6. 正式送審前執行 `npm run mobile:release-check`。目前會因正式識別碼、營運／客服／政策資訊及實機驗收未完成而失敗，這是預期阻擋。

目前使用 `app.littledaily.preview` 作為測試識別碼。不得直接拿它簽署正式商店版本；正式值須依擁有者決定，同時更新 Capacitor、Android namespace/applicationId、Java package 路徑，以及 Xcode Bundle Identifier。

## 實機驗收（尚待逐項完成）

- 第一次啟動、跳過／完成導覽、全工具返回、大字體、橫向、鍵盤、安全區域。
- 新增紀錄、關閉重開、升級保留資料；以測試裝置驗證網站資料空白後的原生副本復原。
- 測試副本寫入失敗、空間不足及通知拒絕／在系統關閉後的提示。
- 通知允許後排程、撤回／完成後取消、關閉提醒、背景與重開、時區與手機時間更改、點擊通知。
- JSON 匯出到 Files／檔案管理器、重新匯入，核對寵物歸屬、購物獎勵、目標與裝飾。
- CSV 匯出後以試算表開啟，確認中文、金額與多行原因。
- 使用試玩時正式資料、正式預算與原生通知不變。
- 兩週外部試用，收集回顧流程與存款概念是否容易理解；不必上傳私人備份。

## 正式上架前仍需完成

- 擁有者設定：填寫 `docs/store-profile.json` 的營運者、客服信箱、正式 HTTPS 隱私／客服網址、正式 App ID、定價方式。
- Android／iOS 開發者帳號與資格、簽章／金鑰安全保存、實機結果與平台建置。
- 驗證目前儲存方案能承受產品的資料量及更新；正式販售前決定是否改為交易型原生資料庫。若改儲存，必須驗證遷移與回復。
- 隱私說明與 Apple Privacy Manifest 依真正發行服務核對；Google Play Data safety／Apple App Privacy 依實際行為填寫，不能直接假定所有項目都是「沒有」。
- 真實裝置商店截圖、功能描述、年齡分級、內容與素材授權；現有網頁截圖不是已驗證的商店素材。
- 收費方案：免費／付費下載由擁有者決定；若另賣 App 內數位內容，需實作平台購買與還原購買後再驗收。目前不收款。
- 沒有登入、雲端同步、廣告或第三方追蹤；這些並非本機產品上架的必選功能，若新增才另做資料／帳戶與安全流程。
