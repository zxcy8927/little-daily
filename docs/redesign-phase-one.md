- 文案先套用「今天的小日子」「想買的先放著，過幾天還想要再說。」作為語氣樣本。

## 本機預覽與確認

1. 開啟 http://127.0.0.1:5182/#/ ，重新整理查看底色、標題、按鈕與日期。
2. 選「新增想買物品」，比較主要、次要與已選取頁籤的狀態；切到「小屋與商店」確認小屋按鈕也使用相同規格。
3. 將視窗縮至手機寬度，確認無橫向捲動；用 Tab 檢查焦點提示。
4. 若伺服器未啟動，在專案目錄執行 npm.cmd run dev -- --host 127.0.0.1 --port 5182 --strictPort。
5. 自動驗證使用 npm.cmd run build:verified。
