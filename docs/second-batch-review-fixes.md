# 第二批審查修正

日期：2026-10-24。對應 U5–U7、C3–C8、A4–A7。

## 架構

ToolWorkspace 改為路由選擇與延後載入入口；料理、預算、待辦、約會各有獨立元件。移除舊版購物分支及其重複記帳／決策邏輯。useToolBook 集中快照儲存、錯誤、刪除復原及收藏操作；WorkspaceFrame 與 EntryEditor 共用外框與編輯功能，食譜及約會資料獨立放在 data/suggestions。

各工具使用 data/books 的專用型別，僅暴露其對應欄位；data/storage 的 Book 保留為舊資料與備份相容邊界。沒有更換 localStorage 鍵或丟棄舊記錄欄位，未更改 JSON 備份格式。

小屋與工具頁在需要時才載入；首頁樣式維持預先載入，避免依賴小屋 CSS。購物倒數改為每分鐘及重新取得焦點時更新。共用工具資料於跨日或取得焦點後更新日期。

## 介面

小屋採選物店、成長裝飾、即將推出三分區；收藏在選物店中切換，付費物品與主題預覽集中到即將推出。房間加入四個可鍵盤操作的定位點，保留微調與確認儲存。試擺不扣款，付費物品仍不能購買。這次沒有加入拖曳或物件重疊檢查。

保留米白／綠色與小兔，工具圖示統一為原創 SVG 像素圖。分隔清單、支出數字摘要、食譜卡採不同版型；共用色彩、圓角及間距變數，移除已不顯示的故事區樣式。正文使用字型原生 400 字重，標題與按鈕強調，輔助小字提高至 12px，部分淡色文字提高對比；不是完整 WCAG 稽核。

## 驗證

63 項資料邏輯測試、10 項元件操作測試通過；正式建置與離線資源檢查通過。新增回歸涵蓋支出來源保留、編輯及 CSV、待辦完成／期限／復原、冰箱食材／採買去重／食譜收藏、約會安排／心得／免費提案，以及房間定位與付費預覽限制。

真正瀏覽器對首頁及四個拆分工具各檢查 320、390、1280 寬，共 15 組皆無橫向溢出，原始結果見 second-batch-layout.json。手機房間定位亦實際操作確認；這些不代表手機 App 實機驗收。

本批修改未部署 Cloudflare，正式站仍須重新部署才會更新。部署文件已改成以目前 Direct Upload、手動部署及 GitHub 自動驗證為準。
