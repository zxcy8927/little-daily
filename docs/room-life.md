# 第三組：小屋

## 完成範圍

- 依裝置本地時間設定 CSS 光線變數：06:00–10:59 早晨、11:00–16:59 午後、17:00–19:59 傍晚、20:00–05:59 夜晚。每分鐘與返回視窗時更新；夜間不顯示日光束，月光主題保留自己的底色。
- 以現有 SVG 上的輕薄色層調整光線，不新增圖片。時段切換直接換色，沒有顏色或濾鏡動畫。
- 小兔約每 45–65 秒完成一段低頻活動，大半時間待機，偶爾短距離移動、坐下再回來。每輪重新隨機挑位置，限制在原有燈與桌旁的空地，避開已擺家具；沒有空位就不移動。
- 滑鼠靠近、鍵盤焦點在小兔上、睏或睡覺時，暫停走動，方便摸摸小兔。縮圖不走動，也不啟動時鐘。
- 三種既有物件加入互動：暖心燈／玻璃燈開關光暈、小盆栽／龜背葉盆栽輕晃、咖啡機／咖啡推車開關蒸氣。家具出現與解鎖條件不變；可以在咖啡主題試住時一次體驗三種互動。
- 支援點擊、Enter、空白鍵與焦點框，開關提供 aria-pressed；縮圖不嵌入可聚焦的按鈕。
- 沿用 motion token、MotionToggle 與 prefers-reduced-motion。動畫只使用 transform 與 opacity。
- 不新增套件、素材或儲存欄位，不改金幣、解鎖與家具擺放邏輯。燈光與蒸氣狀態只保留在當前畫面。

## 驗證

- `npm test`：64 個單元測試、69 個介面測試，共 133 個通過。
- `npm run build`：通過。
- 新增本地時段邊界、時鐘／焦點更新與清理、家具鍵盤操作、開關蒸氣、縮圖無巢狀按鈕、備份不變、移動路線與擋路取消測試。既有動畫檢查同時確認新 CSS 僅使用 transform 與 opacity。
- 390px 手機寬度驗證咖啡主題三種物件，點擊範圍約 65–75px 寬；確認燈光開關、咖啡蒸氣與小屋暫停後移動動畫的播放狀態。

## 本機預覽

本機開啟 http://127.0.0.1:5173/#/house 。若服務未啟動，執行 `npm run dev` 並開啟終端列出的網址。

1. 選「房間風格」，點奶油咖啡館試住，畫面會回到房間。
2. 點燈開關光暈，點盆栽看輕晃，點咖啡機開關蒸氣；試住不扣款也不保存成佈置。
3. 在白天、預算充裕時留意小兔，每輪大半時間不動；將滑鼠移開、焦點移開後才會繼續走動。
4. 小屋右上角圖示可暫停／恢復動畫。系統啟用減少動態效果後，保留光線、開關與表情，移動和家具動畫停用。
5. 首頁已有對應裝飾，或試擺了燈、盆栽、咖啡推車時，也有相同互動。

本組未進入第四組其他工具動畫，未推送或部署。
