# 第三組：食譜、冷靜表單與備份入口

基準 458bed8。依使用者本次授權接續完成第三組；分類保留原名稱。未新增套件、儲存鍵、API 或持久資料欄位。

## 完成

- 搜尋結果與收藏食譜的步驟預設收合。結果卡只留一個主要動作「記這餐的花費」，收藏與「加到採買清單」為次要動作。
- 六道食譜補上一人份試算估值：45、50、55、85、40、40 元。這是含家裡已有食材的示意估值，非即時售價；畫面有清楚註記，資料集中在 src/ui/recipe-costs.ts，方便調整。
- 食譜讀取今日實際預算，試算這餐之後的餘額。記帳面板帶入估值、餐飲分類與食譜名稱，使用者可以改成實際花費。只有按「記下這筆」且儲存成功才新增既有格式的支出；開啟、試算、取消都不扣預算。
- 冷靜清單金額 placeholder 改為淺灰「例如 1500」，加入 decimal 鍵盤提示及預算影響說明。試算以今天為準，不預測冷靜期到期當天；加入清單不會記帳或扣額度。
- 反思區只保留一個可見的「留一句給之後的自己」標題，內部欄位仍有無障礙群組名稱。
- 將既有「匯出備份 / 匯入」直接放到更多頁，減少多層收合。沿用完整 JSON、預覽、合併及失敗保護，不新增另一種備份格式。自動復原點與安裝說明仍保留。
- 預算頁保留像素圖示、柔和圓角與統一陰影，移除該頁返回工具按鈕；四個底部分頁沿用第一組。

## 本機驗收

http://127.0.0.1:5182/#/cooking ：按「找找能煮什麼」，查看估值、預算影響及收合步驟。可開啟記帳面板再取消，確認不會新增支出。需要實際送出時，建議使用測試資料。

http://127.0.0.1:5182/#/shopping ：輸入預計金額，檢查剩餘／超出金額；不送出時不會儲存。展開反思區，標題只出現一次。

http://127.0.0.1:5182/#/more ：直接展開「匯出備份 / 匯入」。下載後確認 JSON 檔案確實存在，再換裝置；匯入先預覽，確認後才合併。自動復原點在同一瀏覽器中，不能代替外部備份。

若預覽服務尚未啟動：npm run dev -- --host 127.0.0.1 --port 5182 --strictPort。
