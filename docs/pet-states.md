# 第一組：小兔

## 已完成

- PixelPet 共用分層 SVG，提供 idle、happy、worried、sleepy、asleep 五種狀態；小屋移除原本重複的小兔圖形。
- 待機眨眼與耳朵輕抖、開心小跳、睡眠呼吸與睡覺符號，使用 CSS steps()；動畫僅改 transform 與 opacity，沿用時間 token。
- 白天額度充裕時待機；預算使用達 80% 時安靜休息；超支時用擔心表情陪伴。22:00–23:59 有睏意、00:00–05:59 睡覺，夜間優先於預算狀況。
- 狀態讀取現有預算，記帳事件、跨分頁更新、返回視窗及每 30 秒時鐘更新，不寫入業務資料。
- 首頁與小屋可點擊或以 Enter／空白鍵摸摸小兔，短暫開心並回話。相鄰點擊間隔不超過兩秒，累積五次出現耳朵彩蛋；回話 2.4 秒後收起。
- 展示用途不增加互動按鈕，決定不買的收據使用開心表情。縮圖保持純展示。
- 尊重 prefers-reduced-motion 與小屋 MotionToggle；沒有新增依賴。

## 驗證與預覽

- `npm test`：64 個單元測試、59 個介面測試，共 123 個通過。
- `npm run build`：通過。
- 新增今日／跨日預算與深夜狀態、點擊與鍵盤、五次彩蛋與間隔重設、壞資料降級、卸載清理、展示替代文字測試；既有動畫限制測試同時檢查新 CSS。
- 瀏覽器確認首頁及小屋點擊、連點彩蛋與暫停動畫。390px 手機寬度下，小兔透明點擊範圍約 54 × 47px。

執行 `npm run dev`，開啟終端顯示的網址（目前 http://127.0.0.1:5173/）。首頁往下看到小屋，點小兔或快速點五次；右上角圖示可暫停與恢復動畫。`#/house` 同樣可操作。系統啟用減少動態效果後，表情與回話保留，動畫停用。

本組未進入記帳手感、房間移動或家具互動；未推送或部署。
