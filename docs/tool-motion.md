# 第四組：其他工具互動

## 完成內容

- 待辦：完成後顯示打勾與整列淡入移動，在清單下方標示已完成區；右滑至少 70px 且垂直偏移小於 35px 可完成。按鈕與垂直捲動不觸發右滑。沿用既有 toggle 儲存規則，僅讓 toggle 回傳儲存是否成功，成功後才觸覺回饋。
- 約會：沿用預算與地點篩選、隨機選擇及收藏規則，新增約 1.5 秒翻卡與「直接看點子」。減少動態效果時直接揭曉。
- 想買：未決定物品顯示向上取整的剩餘天數，到期列有短暫微光；決定不買的成功收據改為硬幣掉入存錢罐。金幣與避免支出計算不變。
- 每週回顧：數字依序滾動，依避免支出、完成待辦、用完食材或記帳情況給小兔總結。可產生 1000 × 1000 PNG 預覽，再由使用者選擇分享或下載；只含彙總，不含逐筆項目或備註。換週清除舊圖片預覽。
- 料理：搜尋結果與已收藏食譜都能開啟「一步一步煮」，一次一個大字步驟。每步可用 1／3／5 分鐘計時、暫停、恢復與清除；切換步驟或關閉會清理計時。計時依結束時間計算，回到畫面時能追上經過時間，不發背景通知。
- 步驟模式嘗試取得 Screen Wake Lock，返回可見畫面時可重新取得；關閉後釋放。裝置不支援或拒絕時顯示提示，不阻擋看步驟。

所有動畫僅使用 transform 與 opacity，沿用 motion token 與 prefers-reduced-motion，小屋 MotionToggle 保持原行為。未新增套件、資料欄位、儲存格式或獎勵規則。

## 分享與裝置限制

原生版沿用現有 @capacitor/share 與 Filesystem，將 PNG 寫入 Cache 後交給系統分享；網頁支援檔案分享時用系統分享，否則下載。取消不顯示失敗提示；真正失敗時保留預覽供重試。

亮屏與原生分享依裝置支援，仍需手機實機驗證。亮屏可能被系統釋放，不能保證背景持續亮屏；本組不新增原生亮屏套件。

API 參考：[Screen Wake Lock](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API)、[Capacitor Share](https://capacitorjs.com/docs/apis/share)。

## 本機預覽

開啟 http://127.0.0.1:5173/ 。若尚未啟動，執行 `npm run dev` 並依終端網址開啟。

1. 更多 → 待辦小本：新增一件事，在文字區向右滑；也能用原有完成按鈕，已完成仍可改回。
2. 更多 → 約會提案：填預算後抽卡，等待揭曉或點「直接看點子」。
3. 想買：查看冷靜天數及到期提示，使用原有到期決定流程試存錢罐動畫。
4. 更多 → 查看本週生活回顧：點「做成分享圖片」，看過預覽再分享或下載。
5. 更多 → 今天煮什麼：搜尋食譜後點「一步一步煮」，試計時、暫停、換步驟與關閉。
6. 系統開啟減少動態效果後，內容與操作照常，翻卡與其他動畫略過。
