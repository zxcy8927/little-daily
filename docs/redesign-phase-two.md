# 第二階段：小屋置頂與首頁主次

日期：2026-10-24。開始前工作目錄乾淨。依使用者回饋，先另存字重修正 commit 970ff61：標題 700、內文與表單 600，保留芫荽／粉圓與備用字體，再開始本階段。

## 修改內容

- 首頁直接展示像素小屋、小兔、家具與氛圍動畫，不再放在收合區塊，也不在初次載入時自動捲走頁面。
- 首頁房間只做展示，讀取既有購物與家具資料；「佈置小屋」直接開啟原有購物頁的小屋與商店分區。購買、試擺與收藏功能仍在，沒有新增寫入流程。
- 想買清單只保留一個明顯的新增入口。到期數量只在大於零時顯示一則提醒；沒有到期但仍有物品時，說明仍在冷靜，不誤顯示成空清單。
- 移除四張等大摘要卡，預算改為大區塊。未記支出時用一句話說明；待辦與真實寵物日記以有內容才出現的文字列呈現，不用空白計數卡佔位。
- 食材與約會提醒需展開才顯示；六個工具、首頁顯示／排序設定、簽到、等級、週回顧、備份、還原與安裝說明放在「生活小本子」。這些功能全部保留。
- 首頁只留頁首的新手導覽重看入口，移除重複邀請區塊；導覽改指向新小屋與小本子，原有自動展開／收合還原繼續使用。
- 從次要工具返回首頁時會展開小本子，焦點回到原工具。從購物返回時，焦點回到唯一的新增入口。
- 清除已移除首頁布局的舊樣式及空白響應式區塊，未增加套件。

## 資料與功能範圍

沒有修改資料結構、儲存鍵、冷靜期、獎勵、家具價格、庫存、備份合併或真實寵物資料。新增的 initialView 只選擇進入購物頁時先顯示清單或小屋，是不保存的畫面狀態。沒有新增 API 或資料移轉。

首頁小兔仍是展示角色；完整隨機對話、時段光線與不買獎勵動畫留待後續階段。商店與其餘工具的全站文案尚未在本階段重寫。

## 本機預覽與確認

1. 開啟 http://127.0.0.1:5182/#/ 並重新整理，查看加厚字體與直接展示的小屋。
2. 按「佈置小屋」，應直接到小屋與商店；返回首頁後按「新增想買物品」，應進入冷靜清單。
3. 展開「生活小本子」，確認六個工具、簽到、週回顧及備份仍可使用。進入待辦再返回，焦點應回到原入口。
4. 重看新手導覽，確認搬移後的工具與備份仍能被帶到。
5. 將視窗縮至 320px／390px，檢查字體、按鈕與橫向捲動。
6. 伺服器未啟動時，在專案目錄執行 npm.cmd run dev -- --host 127.0.0.1 --port 5182 --strictPort。自動檢查用 npm.cmd run build:verified。
