# 購物冷靜期測試指南

本機已提供可獨立試玩的完整流程。啟動專案後開啟 `/#/shopping`，點「開始獨立試玩」。試玩資料僅保留於這次畫面，重新整理或離開工具即結束，不會寫進正式購物、預算或備份。

## 五分鐘測試

1. 加入「衣服」、預計金額 1500、冷靜期 7 天，可選填想買原因。
2. 確認「回顧並決定」尚不可按。點「試玩快轉 7 天」。
3. 回顧並填寫「衣櫃已有類似的」，選擇「決定不買」。
4. 確認避免支出 NT$1,500、已自行存下 NT$0、遊戲金幣 50；小盆栽解鎖，可收起／擺放。
5. 在不買紀錄輸入已自行存下 500，確認成果更新為 NT$500，不會再領一次金幣。
6. 再完成兩筆不買，確認 100／150 金幣分別解鎖暖心燈及星空窗。
7. 另新增一筆，快轉後選擇購買，確認沒有增加避免支出／金幣。試玩記帳只顯示示範提示。
8. 結束試玩，確認正式紀錄不受影響。

## 正式模式

新增物品預設 7 天，也可選 1／3 天。原有舊紀錄仍採 1 天，已完成舊紀錄不追發獎勵。到期後回來回顧，填寫原因並確認決定；目前沒有背景通知。送出後保留決定，避免重新開啟刷獎勵。正式購買可另記入預算，相同來源不會重複入帳。

獎勵以每筆 50 金幣計算，不鼓勵填寫更大價格；50／100／150 金幣為累積解鎖門檻，裝飾不扣款。首頁顯示簽到與購物獎勵合計。所有金幣為遊戲點數。避免支出是原先預計花費，實際存款依使用者自行操作及回報，沒有連接銀行或自動轉帳。

正式紀錄、冷靜天數、金幣、已存金額及裝飾擺放狀態都包含於既有 JSON 備份。請先下載備份再換機；本機版沒有跨裝置同步。

## 交給外部測試者

目前沒有公開測試網址。可交付專案給能啟動專案的測試者，或完成 HTTPS 測試站部署後提供網址。測試站每位使用者的資料留在自己的瀏覽器，沒有共用後台或回報收集服務。

請記下：能否不經說明完成不買流程、是否理解避免支出與實際存款、是否找到解鎖裝飾、哪一步需要協助。不需提交個人財務資料或完整備份。
# 1.4 外部試用補充

除了原有衣服 NT$1,500 的試玩，請加測：

1. 新增物品後按「修改物品」，修改名稱／金額。確認到期時間不變，編輯時不能縮短冷靜天數。
2. 按「撤回物品」，切換「已撤回」，確認沒有增加避免支出或金幣。復原後原到期時間保留。
3. 設定「旅行基金」目標 NT$5,000。避免支出 NT$1,500 時，目標仍是 0；確認實際存下 500 後，目標進度才變為 10%。
4. 每月回顧依決定日期分組。CSV 中的已存金額是這些物品的「目前回報值」，不是銀行的月份入帳紀錄。
5. 網頁版及試玩模式不要求通知權限。原生測試版的系統通知、檔案分享與更新重開，必須另在真實手機測試。

試玩離開或重新整理即結束，試玩目標與紀錄也不會保留。正式資料可由首頁 JSON 備份匯出；原生副本屬同裝置保障，仍需保留外部檔案。
