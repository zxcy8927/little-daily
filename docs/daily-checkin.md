# 第五組：簽到

## 完成內容

- 每天第一次開啟、尚未簽到時，小兔以可收起的非強制招呼卡出現；點小兔才簽到，不會自動領取獎勵。新手導覽結束後才顯示招呼。
- 招呼可在首頁、更多及其他工具頁出現，不自動移動焦點、不擋底部分頁。「更多」原有簽到入口改成摸摸小兔，收起招呼後仍能使用。
- 第一次、隔天、隔幾天回來有不同招呼；回來只說位置替你留著，不顯示漏簽、連續天數或損失。
- 沿用 readGame、nextCheckIn 與既有跨分頁鎖定。每天仍是 10 金幣與 10 經驗值，不改金幣、經驗、等級門檻與日期規則。
- 真正簽到成功後回應與成功觸覺；重複簽到不再加獎勵。儲存失敗不顯示成功或升級卡，回應收起後可重試。
- 等級跨過原有門檻時顯示「成長卡已解鎖」，標示新等級與這次實際增加的金幣／經驗值。這是等級紀念卡，不新增家具解鎖或其他獎勵規則，也不新增收藏資料。
- 動畫僅使用 transform、opacity，沿用 motion token 與 prefers-reduced-motion；小屋 MotionToggle 保持原行為。未新增套件。

## 介面偏好

僅新增獨立裝置標記 `little-daily-greeting-seen-v1`，保存已展示招呼的本地日期；不加入紀錄備份，不更動既有資料格式，也不觸發業務紀錄儲存事件。拒絕保存偏好時仍可顯示招呼，重新開啟可能再出現。

## 驗證

- `npm test`：64 個單元測試、88 個介面測試，共 152 個通過。
- `npm run build`：通過。
- 新增招呼不自動領獎、每日只顯示一次、更多常駐入口、升級實際獎勵、儲存失敗與重試、其他分頁已簽到時不重領、跨日、StrictMode、導覽先後順序、偏好保存失敗與歡迎回來語氣測試。
- 390px 手機寬度驗證招呼、收起後的常駐入口與升級卡。使用獨立 5187 網址，經既有備份匯入測試進度，簽到後由 200 金幣／90 經驗值變成 210 金幣／100 經驗值，顯示 LV. 2 成長卡及已簽到狀態。
- 主要預覽網址未用來簽到或匯入測試資料；觸覺仍待原生手機實機驗證。

## 本機預覽

開啟 http://127.0.0.1:5173/ 。若服務未啟動，執行 `npm run dev` 並開啟終端列出的網址。

1. 尚未簽到時，當天第一次開啟會看到小兔招呼；若有導覽，先完成或跳過導覽。
2. 點招呼裡的小兔，或到「更多」下方的簽到區摸摸小兔；確認金幣與經驗各增加 10。
3. 重新整理當天不再跳招呼，更多按鈕顯示「今天已記下」且不能重複領獎。
4. 原有等級門檻跨越時顯示成長卡；收起卡片不再增加獎勵。
5. 系統開啟減少動態效果時，簽到與卡片照常可用，動畫略過。

本組未推送或部署。
