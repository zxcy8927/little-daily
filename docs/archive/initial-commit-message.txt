建立 Little Daily 1.6：整合六項日常工具、購物冷靜期與像素小屋收藏

功能內容
- 提供料理、購物冷靜期、日常預算、寵物日記、待辦與約會六項工具
- 加入新手導覽、首頁工具排序、簽到金幣、生活摘要與每週回顧
- 完成購物冷靜期、到期決定、避免支出、自行存下、目標與每月 CSV 匯出
- 提供獨立試玩與七天快轉，試玩資料不寫入正式紀錄
- 新增三種像素小屋風格、十件金幣家具與六件付費物品預覽
- 支援家具試擺、位置微調、購買收藏、收起與重複擺放；付費收款尚未開放
- 將購物頁拆成清單、小屋與商店、省錢回顧，收合說明、收藏與首頁次要資訊

資料保存與手機準備
- 支援本機資料、JSON 備份合併、自動復原點與跨分頁過期快照保護
- 整合 PWA 離線資源、Android／iOS Capacitor 專案、原生備份與提醒介面
- 補齊隱私說明、問題回報、字型及第三方授權

版本控制與部署準備
- 排除依賴、建置產物、暫存工具、憑證、環境變數與本機 QR Code
- 新增 GitHub Actions 自動測試、正式建置、資源檢查與產物保存
- 記錄正式網域資料遷移、部署方式與回復舊版程序

驗證：61 項自動測試通過，正式建置與離線資源檢查通過。
限制：尚未完成原生手機商店上架、真實付款與跨裝置雲端同步。
