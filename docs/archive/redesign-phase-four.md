# 第四階段：其餘工具與共用文案

2026 年 10 月 24 日。開始前 Git 工作目錄乾淨，基準為 eafc465。本階段只在本機提交，不推送或部署。

## 改動

- 重寫預算、待辦、料理、約會與寵物日記的說明、空狀態及輸入提示。保留清楚的「編輯／刪除／取消／儲存」等操作名稱，不為換字而換字。
- 將共用儲存成功、失敗、空間不足、權限限制與分頁衝突提示收在 src/ui/copy.ts。購物、首頁設定、生活工具、寵物及備份使用共用錯誤呈現，避免直接顯示英文例外。
- 日期僅在畫面轉成「10 月 24 日（六）」；跨年加年份，復原點加本地 24 小時制時間。月份顯示年份與月份，日期輸入仍由裝置原生控制項處理。
- 金幣統一使用「金幣」，經驗值取代 EXP；購物 CSV 僅將「遊戲金幣」欄名改為「金幣」，欄位順序、數值與日期格式不變。
- 新手導覽、備份與復原、安裝、通知、隱私及問題回報頁改用簡短口語。備份合併原則、無雲端同步、資料清除風險、通知不含物品名／金額等事實仍保留。
- 手機驗證發現獨立工具的導覽缺少樣式，補上可橫向捲動的導覽列與 44px 點按高度、目前頁面及鍵盤焦點樣式，沿用集中色票。
- 維持原本較厚的內文／標題字重，說明靜態頁也使用 600 字重。未新增套件。

## 保持不變

資料結構、API、儲存鍵、日期值、寵物種類與日記分類分隔符、篩選判斷值、食譜與約會點子識別名稱、金幣計算、通知排程、合併與復原流程皆不變。只整理了部分原本壓成單行的程式排版，沒有刪除功能。寵物隨機對話與時段光線留待第五階段。

## 本機預覽與驗收

開啟 http://127.0.0.1:5182/#/ 。若預覽未啟動，在專案執行 npm run dev -- --host 127.0.0.1 --port 5182 --strictPort。

1. 在「生活小本子」開啟待辦、預算、料理、約會及寵物日記，查看提示與空狀態；用日期選擇器切換日期，確認顯示好讀、重新開啟後日期不變。
2. 編輯既有紀錄後取消，確認內容保留；刪除一筆後使用復原，確認原紀錄回來。
3. 查看「資料備份、還原與安裝」，展開備份及自動復原點；匯入前會先預覽，重複紀錄維持目前內容。測試匯入請使用獨立瀏覽器或測試資料，勿拿未備份的正式紀錄試。
4. 將畫面縮到手機寬度，確認導覽可左右滑動、表單未超出畫面。點開隱私與問題回報說明，確認文字與原本行為一致。
