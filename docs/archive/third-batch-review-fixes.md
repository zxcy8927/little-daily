# 第三批：操作失敗與導覽整合

完成日期：2026-10-24。此批只更新本機與 GitHub，未部署 Cloudflare Pages。

## 完成項目

- 新手導覽會暫時展開週回顧、備份的巢狀收合區塊，離開該步後還原；原本已展開的內容保持原狀。購物步驟改指向固定存在的首頁快速操作，不受工具隱藏設定影響。
- 購物回顧儲存失敗時，在對話框內顯示錯誤，保留輸入的決定原因，允許重試。結算錯誤也不再直接關閉視窗。
- 取消回顧會返回原操作按鈕；結算後原按鈕消失時，焦點返回目前的購物功能頁籤。首次開頁不會因此搶走焦點。
- 畫面或延遲載入元件出錯時提供重新開啟入口，說明重新載入會捨棄未儲存輸入；不清除本機紀錄。
- 待辦初次使用會提示新增位置；搜尋或篩選無結果時可直接顯示全部待辦。
- 啟動程序晚於頁面 load 時仍會註冊離線服務，註冊失敗會送出既有的離線錯誤事件。

## 驗證

- 63 項資料／流程測試通過。
- 17 項介面測試通過，其中本批新增 7 項，涵蓋導覽巢狀展開還原、待辦空白與搜尋還原、取消編輯的焦點與資料保留、購物寫入失敗後重試只發一次獎勵、錯誤畫面保留資料，以及離線服務的兩種載入時機。
- 正式建置、TypeScript 與發布資源檢查通過。
- 瀏覽器以 390×844、320×740 模擬手機：導覽目標可展開與高亮、無橫向溢出；320px 導覽卡片位於 x=16–304、y=149–591，仍在畫面內。
- 完成導覽後，原本收合的區塊恢復收合；實際 Escape 鍵可關閉導覽並將焦點返回「新手導覽」。

## 限制

模擬手機檢查不等於 Android／iOS 實機驗收。本批沒有啟用真實付費、商店內購、雲端同步，也未變更正式站部署。
