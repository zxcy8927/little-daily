# 第二組：記帳手感

## 完成範圍

- 分類標籤與送出按鈕加入按壓縮放；切換分類呼叫輕觸回饋，記帳／編輯成功後呼叫成功回饋。儲存失敗不播放成功觸覺，也不清空輸入。
- 首頁、記帳面板與預算頁使用逐字滾動金額，螢幕閱讀器直接讀取最終金額。支援負數、小數、千分位與連續更新。
- 記帳面板及預算頁表單提供目前所選日期的剩餘預算。成功送出後，金額變成金幣飛向可見的預算卡；捲動、視窗改變或卸載時收起動畫。
- 首頁每天第一次看到昨日記帳時顯示結算。守住目前每日預算時，小兔開心並收下一枚動畫金幣；超支時只有陪伴語句。昨日無紀錄或讀取失敗時隱藏。
- 結算明確標示「按目前每日預算回看」，因既有資料沒有歷史每日預算；不推測昨天曾設定的額度。
- 不改記帳、獎勵規則或資料格式。結算金幣是視覺回饋，不增減金幣餘額。
- 僅新增獨立介面標記 `little-daily-yesterday-seen-v1`，記下已展示日期，避免重開反覆提醒；不包含在紀錄備份。瀏覽器拒絕保存時仍可記帳，但重新開啟可能再看到卡片。
- 動畫僅使用 transform 與 opacity，沿用 motion token 及 prefers-reduced-motion；既有小屋 MotionToggle 不變。沒有新增套件。

## 驗證

- `npm test`：64 個單元測試、64 個介面測試，共 128 個通過。
- `npm run build`：通過。
- 測試涵蓋分類與成功觸覺、失敗保留輸入、滾動數字的最終可讀金額、昨日結算首次顯示與跨日、超支陪伴、備份資料與金幣不變、錯誤降級、金幣收尾及減少動態效果。
- 在獨立本機網址以 390px 手機寬度操作記帳面板與預算頁，確認成功記帳、金額清空、分類保留、預算同步更新、昨日結算及重開不重複。未使用主要預覽網址的紀錄測試。
- 觸覺呼叫通過模擬測試；實際手機震動仍需原生 App 實機驗證。

## 本機預覽

執行 `npm run dev`，開啟終端列出的網址。目前為 http://127.0.0.1:5173/。

1. 首頁按「記一筆」，切換分類並輸入支出；送出後看剩餘預算滾動與金幣飛入，金額欄會清空並重新取得焦點。
2. `#/budget` 的表單有同樣回饋；用既有「撤回」或編輯流程檢查數字更新。
3. 有昨天記帳資料時，當天首次開啟首頁會看到昨日結算；關閉或重新開啟不反覆顯示。沒有昨天紀錄時不顯示。
4. 系統開啟減少動態效果後，直接顯示最終數字並隱藏飛行金幣，文字回饋照常保留。
5. 「更多 → 互動設定」的觸覺開關預設關閉，網頁不震動；支援的原生手機 App 才能驗證實際震動。
