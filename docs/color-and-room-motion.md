# 彩色介面與小屋動態展示

完成日期：2026-10-24。沿用圓潤字體與像素房間，增加工具辨識度及展示氛圍。

## 介面

- 料理蜜桃橘、購物莓果粉、預算奶油黃、寵物薄荷綠、待辦薰衣草紫、約會天空藍。
- 首頁摘要卡、工具卡、工具頁標題、錢包與快速操作加入分區配色、圓角與柔和陰影。
- 卡片保留工具名稱及圖示，顏色不是唯一辨識方式。

## 小屋

- 免費小屋改為暖杏牆面、木色地板與青綠窗景，搭配日光和漂浮微塵。
- 月光主題增加閃爍星光；咖啡主題增加杯口熱氣。
- 小兔呼吸、主題淡入、家具試擺外框明暗變化與家具淡入效果。
- 動畫控制置於展示列，不遮擋家具；可暫停與繼續。系統設定減少動態效果時停用動畫與卡片位移。
- 裝飾層不接收點擊、不加入螢幕閱讀器內容，不更動金幣、購買與擺放資料。

- 既有 63 項單元／流程測試及 17 項介面測試通過。
- 本機瀏覽器確認六張工具卡使用不同色系，320px 與 390px 寬度沒有橫向溢出。
- 確認月光主題產生五顆動畫星光；暫停後七顆微塵的動畫狀態皆為 paused，繼續後為 running。
