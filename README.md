# Little Daily — 網頁與手機測試版 1.6

像素小兔與粉圓字體的生活工具網站（React + TypeScript + Vite）。

## 本機啟動

在 Windows PowerShell 執行：

```
npm.cmd install
npm.cmd run dev
```

開啟終端機顯示的網址。開發伺服器已啟動時，重新整理即可看到修改。

## 本機完整版 1.0

- 首頁顯示今日剩餘預算、到期待辦、冷靜期到期購物與寵物紀錄，並列出優先待辦、已安排約會與待買食材。
- 六個工具有固定網址，可直接開啟、重新整理、使用上一頁與下一頁；工具頁可由導覽列互相切換。
- 首頁摘要在回首頁、重新取得焦點與跨日後更新；備份匯入也會更新首頁。
- 紀錄儲存前會比對讀取時的資料快照；發現其他頁面變更時，提示載入最新資料，不直接覆寫。
- 簽到前重讀進度；支援瀏覽器鎖定時，同瀏覽器多頁簽到會依序處理。
- 匯入備份前顯示各工具筆數、寵物數與採買項目；合併保留目前設定和重複紀錄。
- 食材清單清除已買項目後可復原，頁尾提供基本使用說明。

## 六個工具功能

### 寵物日記

- 支援多隻寵物，分別儲存名字、種類、選填生日與日記。
- 舊版名字與紀錄自動連到同一個寵物資料，未命名的舊日記顯示為「我的寵物」。
- 修改名字不會改變紀錄歸屬；新增、編輯、搜尋和復原刪除保留寵物關聯。
- 依日期／全部日期、照護分類查看紀錄，顯示吃飯、喝水、散步、清潔、玩耍等紀錄筆數。
- 寵物資料可收起、恢復使用；收起期間日記可查看，暫停新增與修改。
- 備份包含寵物資料及紀錄歸屬，同一 ID 的寵物以目前資料為準；保留對舊版備份的支援。
- 寵物資料讀取失敗時不覆寫原始資料；生日可留白，手動輸入時不可晚於今天。

### 其餘五個工具

- 今天煮什麼：記住查詢食材，支援料理時間與食材齊全篩選；缺少食材可去重加入採買清單，勾選已買，也可手動補充。
- 買之前想想：已買商品可按「記入今天支出」，帶入日常預算的購物分類；記錄來源避免重複入帳。
- 日常預算：餐飲、交通、購物、居家、娛樂、其他分類；按日／月看明細，分類篩選、月分類圖表及目前清單 CSV 匯出。
- 待辦小本：可選期限、優先順序；今天到期與已逾期篩選，自動按完成狀態、期限與優先順序排序，記錄完成日期。
- 約會提案：收藏可填安排日期與心得、標記去過；可篩選想去／去過，保留完成日期。
- 備份包含新增欄位、食材採買及購物來源。合併也依購物來源去重，採買清單保留現有勾選狀態。

## 基本功能

- 食材配對 6 道家常菜，顯示缺少食材與步驟，可收藏常用食譜。
- 購物清單支援 1／3／7 天冷靜期，到期可確認不買或購買；考慮中物品可修改及撤回復原，已確認決定保留紀錄。
- 每日預算、按日期記帳、月累計支出；金額以分加總。
- 寵物日記可儲存寵物名字，提供照護分類紀錄與日期檢視；名字包含於備份。
- 待辦完成與狀態篩選。
- 依兩人預算、室內外條件抽約會點子，可收藏。
- 記帳、購物、照護及待辦紀錄可編輯、搜尋，刪除後可復原上一筆。
- 首頁可下載 JSON 備份、選擇備份預覽並確認合併匯入。
- 保留第一版資料格式與儲存位置，舊紀錄不需搬移。

## 備份與資料保存

資料儲存在目前網站網址與瀏覽器，清除網站資料會刪除紀錄，不會跨裝置同步。
備份檔含個人紀錄，請自行妥善保存。匯入只在本機處理。

合併時相同 ID 的紀錄、現有每日預算與簽到進度以目前資料為準；新紀錄才會加入。
匯入不是覆寫還原，因此不會把現有編輯退回舊版本，也不會刪除現有紀錄。
備份只讀寫 Little Daily 的指定儲存項目。錯誤格式不會寫入；遇到儲存寫入失敗會嘗試復原原值。
檔案上限 10 MB、單工具上限一萬筆紀錄、寵物上限 50 隻、冰箱食材上限 500 項、食材採買清單上限 500 項。

復原刪除限目前工具頁的上一筆，離開頁面後不保留復原紀錄。採買清除的復原也限目前頁面。未儲存的表單輸入在切換工具或重新整理後不保留。
購物冷靜期以裝置時間起算，新紀錄預設 7 天，可選 1／3 天；原有未設定天數的紀錄沿用 1 天。已買商品需按「記入今天支出」才加入記帳，日期為操作當天。已完成決定的商品保留內容，實際支出如有差異請到預算工具修改；刪除預算支出後可重新入帳。
食譜與約會使用內建資料。日期與每日簽到依裝置本地時間計算。

## 驗證

```
npm.cmd test
npm.cmd run build
```

自動測試涵蓋舊資料相容、備份往返、合併去重、無效資料拒絕、寫入失敗復原、多寵物紀錄歸屬與舊版日記轉換；另涵蓋購物入帳去重、分類金額精度、待辦期限排序、料理篩選、採買去重與 CSV 跳脫；整合測試涵蓋首頁六工具摘要、網址導覽、重複簽到與過期資料快照拒絕；產品測試涵蓋冷靜卡、跨年週界線、週回顧金額、食材到期配對與首頁設定備份。

粉圓字體隨專案提供，授權見 public/huninn-LICENSE.txt。


## 發佈檢查

- 執行測試與正式建置。
- 由網址直接開啟工具、重新整理，確認仍在同一工具。
- 驗證導覽列、瀏覽器上一頁／下一頁及回首頁摘要。
- 用備份檔帶入另一個瀏覽器，確認紀錄與寵物歸屬。
- 在多個頁面使用同一工具時，若出現資料已更新提示，先複製未儲存內容，再載入最新紀錄。

## 1.4 購物與手機測試準備

已補齊購物物品修改／撤回復原、存錢目標、月回顧與 CSV；Android／iOS Capacitor 原始專案、通知與原生備份／系統分享已接好。尚未產出或簽署 APK／AAB／IPA，原生功能仍待實機驗收。

- `npm run mobile:sync`：建置並同步 Android／iOS 資源。
- `npm run mobile:check`：靜態專案與資源一致性檢查，不代表原生編譯。
- `npm run mobile:release-check`：送審前檢查，目前因正式資訊未填與實機未驗收而預期失敗。
- [手機準備與上架狀態](docs/mobile-release-readiness.md)、[購物測試指南](docs/shopping-playtest.md)。

正式商店資訊填寫於 `docs/store-profile.json`；測試 App ID `app.littledaily.preview` 必須在正式簽章前更換。不要將金鑰、憑證或密碼提交到專案。
